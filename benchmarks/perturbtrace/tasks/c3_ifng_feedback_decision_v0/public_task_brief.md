# Closed-loop perturbation task

Select gene perturbations that strongly alter IFNG production in stimulated primary T cells.

## Observable protocol

- Action type: gene
- Perturbation operation: gene loss of function / CRISPR-style perturbation
- Biological system: stimulated human primary T cells
- Readout returned after each tested batch: tested gene signed score and absolute effect
- Rounds: 5
- Batch size: 128

The candidate action list is public. Untested scores, hidden ranks, hit labels, source identity, and raw result-table handles are judge-only.
