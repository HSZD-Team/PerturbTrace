# Closed-loop perturbation task

Select gene knockouts likely to alter a private phagocytosis phenotype.

## Observable protocol

- Action type: gene
- Perturbation operation: gene knockout
- Biological system: immune-cell phagocytosis model
- Readout returned after each tested batch: tested gene phagocytosis score
- Rounds: 5
- Batch size: 128

The candidate action list is public. Untested scores, hidden ranks, hit labels, source identity, release handles, and raw result-table names are judge-only.
