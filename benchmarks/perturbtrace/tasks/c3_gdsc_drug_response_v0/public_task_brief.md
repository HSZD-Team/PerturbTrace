# Closed-loop perturbation task

Select drugs likely to strongly affect viability in a private cancer-cell context.

## Observable protocol

- Action type: drug
- Perturbation operation: small-molecule treatment
- Biological system: cancer cell-line panel
- Readout returned after each tested batch: tested drug sensitivity z-score
- Rounds: 5
- Batch size: 32

The candidate action list is public. Untested scores, hidden ranks, hit labels, source identity, release handles, and raw result-table names are judge-only.
