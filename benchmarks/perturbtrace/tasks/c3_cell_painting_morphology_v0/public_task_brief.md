# Closed-loop perturbation task

Select perturbations likely to produce a private morphology phenotype.

## Observable protocol

- Action type: compound_or_gene_perturbation
- Perturbation operation: compound or genetic perturbation
- Biological system: image-profiled cell models
- Readout returned after each tested batch: tested perturbation morphology-projection score
- Rounds: 5
- Batch size: 64

The candidate action list is public. Untested scores, hidden ranks, hit labels, source identity, release handles, and raw result-table names are judge-only.
