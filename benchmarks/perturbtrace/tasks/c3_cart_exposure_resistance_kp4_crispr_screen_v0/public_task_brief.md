# Closed-loop perturbation task

Select gene knockouts likely to alter a private engineered immune-cell exposure phenotype.

## Observable protocol

- Action type: gene
- Perturbation operation: gene knockout
- Biological system: cancer cell model under a private engineered immune-cell exposure
- Readout returned after each tested batch: tested gene immune-exposure response score
- Rounds: 5
- Batch size: 128

The candidate action list is public. Untested scores, hidden ranks, hit labels, source identity, release handles, and raw result-table names are judge-only.
