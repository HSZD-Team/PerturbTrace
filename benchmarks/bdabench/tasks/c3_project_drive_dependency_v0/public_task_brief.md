# Closed-loop perturbation task

Select gene knockdowns likely to strongly reduce viability in a private cancer-cell context.

## Observable protocol

- Action type: gene
- Perturbation operation: gene knockdown
- Biological system: cancer cell-line panel
- Readout returned after each tested batch: tested gene dependency score
- Rounds: 5
- Batch size: 128

The candidate action list is public. Untested scores, hidden ranks, hit labels, source identity, release handles, and raw result-table names are judge-only.
