# Closed-loop perturbation task

Select gene knockouts likely to strongly alter a private primary-T-cell immune-function phenotype.

## Observable protocol

- Action type: gene
- Perturbation operation: gene knockout
- Biological system: primary human T cells
- Readout returned after each tested batch: tested gene phenotype score
- Rounds: 5
- Batch size: 128

The candidate action list is public. Untested scores, hidden ranks, hit labels, source identity, release handles, and raw result-table names are judge-only.
