# Closed-loop perturbation task

Select genes mediating lysosomal choline recycling under choline-limited growth.

## Observable protocol

- Action type: gene
- Perturbation operation: gene knockout
- Biological system: cells in medium lacking free choline
- Readout returned after each tested batch: tested gene score
- Rounds: 5
- Batch size: 32

The candidate action list is public. Untested scores, hidden ranks, hit labels, source identity, and raw result-table handles are judge-only.
